# Univ StudyMachine 학생 안내

강의자료와 기출문제를 올리면 시험 범위에 맞춘 개념 정리, 제공된 문제의 해설, 학습계획과 복습 자료를 준비합니다. 기본 언어는 한국어입니다. 먼저 올린 자료를 확인하고, 꼭 필요한 정보만 한 번에 최대 8개까지 묻습니다. 한 번 답하면 나머지 정리와 파일 제작은 에이전트가 이어서 진행합니다.

## 시작하기

스킬을 사용할 수 있도록 설정된 대화에서 강의계획서, 시험 공지, 강의자료, 필기, 기출문제와 해설을 함께 올려 주세요. 실제로 읽을 수 있는 파일이어야 하며, 수식이나 그림이 있는 문제는 원본 페이지가 선명할수록 좋습니다.

처음에는 다음처럼 한 번 요청하면 됩니다.

> $univ-studymachine 이 자료들로 시험 대비해 줘.

과목, 시험 일시, 범위, 공부할 수 있는 시간이 이미 정해졌다면 같은 메시지에 적어도 됩니다. 자료나 메시지에서 확실히 확인한 정보는 다시 묻지 않습니다. 프로그램 실행, 별도 스킬 선택, 파일 변환 명령은 학생이 할 일이 아닙니다.

## 질문에는 한 번에 답하기

빠진 정보가 있으면 한 메시지에서 묻습니다. 질문 수는 최대 8개이며, 모두에게 똑같은 8개를 묻는 것은 아닙니다. 예를 들어 다음처럼 답할 수 있습니다.

> 선형대수학이고 시험은 10월 30일 오후 2시, 한국 시간이에요. 범위는 2장 행렬과 역행렬까지고 평일 60분, 주말 120분 가능해요. 계산형 시험이고 개념은 한 번 봤지만 역행렬 계산이 약해요. 목표는 B+예요. 교수님은 계산 과정도 쓰라고 하셨어요.

모르는 내용은 `미정`이라고 적어 주세요. 시험일이나 공부 시간이 없으면 임의의 날짜와 시간을 만들지 않고 조건부 계획과 한계를 설명합니다. 답변 뒤에 일상적인 확인 질문을 반복하거나 별도 실행 지시를 요구하지 않습니다. 읽지 못한 자료는 읽었다고 처리하지 않고, 확인 가능한 범위부터 진행합니다.

기출이 확인되지 않았을 때는 같은 질문 묶음 안에서 새 연습문제 생성 여부를 물을 수 있습니다. `예`라고 분명히 답했을 때만 생성 대상이 됩니다. 답하지 않거나 `아니요`라고 하면 만들지 않습니다. 기출 자료가 있거나 기출로 의심되는 파일을 읽지 못한 경우에는 동의 여부와 관계없이 새 문제를 만들지 않습니다.

## 받는 자료와 먼저 볼 파일

완료 안내에서 실제로 만들어진 파일과 제한사항을 확인하세요. 우선 `00_시험대비_안내.md`를 읽고, 그 안의 시작 행동을 따른 뒤 `05_시험일까지_학습계획.md`의 첫 학습 블록을 진행하면 됩니다.

| 파일 | 쓰임 |
| --- | --- |
| `00_시험대비_안내.md` | 과목, 시험 정보, 자료 구성, 시작 행동과 중요한 한계 |
| `01_시험범위_자료검증.md` | 읽은 파일, 빠진 내용, 확인된 범위와 불확실한 범위 |
| `02_시험범위_개념총정리.md` | 선수 개념부터 이어지는 정의, 공식, 풀이 절차와 주의점 |
| `03_기출문제_출제경향_분석.md` | 확인 가능한 기출의 주제 분포와 과거 빈도; 기출이 있을 때만 제공 |

| `05_시험일까지_학습계획.md` | 가능한 시간 안의 학습, 복습, 오답 정리와 여유 시간 |

적용되지 않는 파일은 생략합니다. 다운로드가 불가능한 환경에서는 가능한 방식으로 본문을 제공하고 파일 제공의 한계를 알립니다. PDF는 변환과 화면 확인이 가능한 경우에만 추가할 수 있습니다.

## 기출과 해설을 사용하는 방법

기출이 있으면 그 문제를 원문 그대로 사용합니다. 숫자나 조건을 바꾼 변형 문제, 새 진단 문제, 가상의 모의고사를 자동으로 추가하지 않습니다. 한 회분만 있으면 그 한 회분을 그대로 시간 제한 연습에 다시 사용할 수 있습니다.

공식 해설이나 교수님 해설이 있으면 먼저 연결합니다. 답만 있는 정답표와 일부만 풀린 해설은 그대로 남기고 빠진 과정에만 `AI 작성 해설`을 덧붙입니다. 기존 해설끼리 충돌하거나 풀이를 검증하지 못한 부분은 따로 표시합니다. 정답표만 보고 원래 없던 문제를 거꾸로 만들지 않습니다.

기출에서 자주 나온 주제라는 말은 제공된 과거 시험에서 확인된 사실입니다. 다음 시험의 출제 확률이나 성적 보장은 아닙니다. 개념 설명과 풀이에는 원본 파일과 페이지·슬라이드 등의 근거가 연결되어야 합니다.

## 이후 대화에서 이어가기

첫 준비가 끝난 뒤에는 필요할 때 평소 말투로 요청하면 됩니다. 다음 문장은 초기 결과를 받기 위한 추가 절차가 아닙니다.

- `이 과목 이어서 오늘 할 공부를 알려 줘.`
- `제공한 기출 1번 (나)의 역행렬 계산 과정을 설명해 줘.`
- `기출 1번 (나)를 틀렸어. 행렬식의 부호를 잘못 계산했어.`
- `기출 2번의 주제 분류가 잘못된 것 같아.`
- `어제 계획을 못 했어. 남은 시간에 어떻게 공부하면 좋을지 설명해 줘.`

맞고 틀린 기록은 실제로 푼 결과를 알려 주었을 때만 남깁니다. 자료가 만들어졌거나 설명을 읽었다는 이유만으로 숙련도가 오른 것으로 처리하지 않습니다. 저장된 자료에 접근할 수 있어야 다른 대화에서도 이어갈 수 있습니다.

시험일이나 공부 시간이 바뀌었다고 알려 주면 에이전트가 저장된 정보를 갱신하고 지정한 시작일 이후의 계획과 자료를 다시 만들 수 있습니다. 새 문제 생성 동의를 철회하면 다시 만든 자료에서 생성 문제와 해당 파일도 제거합니다. 다만 이전에 내려받은 파일까지 자동으로 회수하지는 않습니다.

일정 갱신에도 한계는 있습니다. 실제로 끝낸 학습 블록의 분량을 모두 추적하지 않으므로, 이미 공부한 내용이 다시 배정될 수 있습니다. 시험 범위의 글자만 바꿔서는 개념과 문제 분류까지 자동으로 다시 해석하지 않습니다. 에이전트는 변경된 범위를 다시 확인하고 결과를 검토해야 합니다. 단순히 이어가기를 요청했다고 밀린 날을 자동으로 감지해 조정하는 것은 아닙니다.

## 알아둘 제한사항

- 흐린 스캔, 수식, 표와 그림은 잘못 읽힐 수 있습니다. 원본 화면을 확인할 수 없는 부분은 확인하지 못했다고 표시합니다. 읽지 못한 기출 때문에 새 문제 생성이 허용되지는 않습니다.
- 개념 이해와 풀이 작성은 호스팅 에이전트가 수행합니다. 자료를 추출하는 프로그램만 실행해서 모든 과목의 정답이 자동으로 검증되는 것은 아닙니다.
- 다른 언어를 요청하면 질문과 완성 문서의 제목·안내·설명도 에이전트가 번역합니다. 이를 위해 내부에서 문서를 한 번 더 만들 수 있지만 학생이 추가로 답하거나 실행할 필요는 없습니다. 원래 제공한 문제·해설 문장은 그대로 보존하고 번역 설명을 덧붙일 수 있으며, 파일명은 한국어로 유지합니다. 번역이 끝나지 않으면 부분 완료로 알립니다. 번역의 의미와 정확성은 에이전트가 검토해야 합니다.
- ChatGPT Work에서의 실제 설치와 실행은 아직 검증되지 않았습니다. 개발자 컴퓨터에 있는 파일과 프로그램이 Work에서 그대로 보이는 것은 아닙니다.
- 개인 자료와 결과는 구현 저장소 밖의 과목별 비공개 위치에 보관합니다. 기본 동작으로 제3자 문서 업로드 서비스에 보내지 않습니다. 호스팅 서비스의 자체 자료 처리 정책은 별도로 적용됩니다.
- 자동 삭제나 영구 보관, 환경 간 자동 동기화는 보장하지 않습니다. 로컬 저장 자료는 직접 정리할 때까지 남을 수 있습니다. 보관 위치를 확인하고 필요한 자료는 안전하게 관리하세요.

`부분 완료` 안내가 있으면 어느 파일이나 풀이가 미확인인지 먼저 확인하세요. 확인하지 못한 범위를 포함한 완성본이나 특정 성적을 보장하지 않습니다.
